# SSO

[Mailinator Enterprise](https://www.mailinator.com/pricing/) subscriptions support Single Sign-On (SSO) using SAML.&#x20;


## Configuration Overview

In general the process for configuring SSO with Mailinator is:

1. We start the integration on our side
2. Someone on the customer's side joins the Mailinator team, visits the SSO Settings page, and does the metadata exchange (downloads our metadata, and uploads your metadata).
3. We complete the setup on our side
4. We test


:::tip
Please contact support [support@manybrain.com](mailto:support@manybrain.com?subject=sso) for more information or to start the configuration.
:::
