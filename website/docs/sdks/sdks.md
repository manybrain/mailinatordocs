# SDKs

Mailinator provides [several official SDKs](https://github.com/manybrain):

* [Java](https://github.com/manybrain/mailinator-java-client)
* [Javascript](https://github.com/manybrain/mailinator-javascript-client)
* [C#](https://github.com/manybrain/mailinator-csharp-client)
* [Go](https://github.com/manybrain/mailinator-go-client)
* [Ruby](https://github.com/manybrain/mailinator-ruby-client)
* [Python](https://github.com/manybrain/mailinator-python-client)

Code examples for each SDK are available in the [Mailinator Docs repo](https://github.com/manybrain/mailinatordocs/tree/main/api-examples).

API Authentication details can be found within the [API reference](/docs/api/).
