# Postman

Use Postman to explore the Mailinator API, test requests manually, and prototype email or SMS workflow checks before moving them into automated test suites.

Mailinator provides a pre-built Postman collection so you can copy the collection, add your API key, and start sending requests quickly.

<a href="https://www.postman.com/mailinator-api/mailinator/collection" target="_blank" rel="noopener noreferrer">Open the Mailinator Postman collection</a>
